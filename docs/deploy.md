# Розгортання на Render

Застосунок працює як один Docker-сервіс `lms` (API разом із зібраним клієнтом) і база `lms-db`. Рішення обґрунтовано в
[ADR 0017](adr/0017-hosting.md). Конфігурація лежить у `render.yaml` у корені репозиторію.

## Одноразове налаштування

1. Зареєструйтеся на [render.com](https://render.com) через GitHub.
2. **New → Blueprint**, оберіть репозиторій `AlexandraKurylo/lms`, гілку `main`. Render прочитає `render.yaml` і покаже
   сервіс `lms` та базу `lms-db` (обидва на тарифі Free).
3. Натисніть **Apply**. Змінні `DATABASE_URL` (з бази), `JWT_SECRET` (генерується) і `COOKIE_SECURE` задаються самі.
4. Дочекайтеся, поки база стане **Available**, а розгортання сервісу `lms` завершиться (у логах `api listening`).
   Перша збірка триває кілька хвилин.
5. Публічне посилання виглядає як `https://lms-xxxx.onrender.com`: сертифікат HTTPS видає Render.

Якщо Blueprint не вдається, створіть вручну: **New → PostgreSQL** (Free, версія 16), потім **New → Web Service** з
репозиторію, **Language: Docker**, **Instance Type: Free**, **Health Check Path:** `/api/ready`, змінні `DATABASE_URL`
(внутрішній URL бази), `JWT_SECRET` (щонайменше 32 символи), `COOKIE_SECURE=true`.

## Демо-дані

Таблиці створюються самі під час старту сервісу (`prisma migrate deploy`). Дані завантажуються один раз з вашого
комп'ютера. У базі `lms-db` на вкладці **Connections** скопіюйте **External Database URL**, допишіть у кінець
`?sslmode=require` і в каталозі `server` виконайте (PowerShell):

```powershell
$env:DATABASE_URL = "<зовнішній URL бази>?sslmode=require"
npm run db:seed
Remove-Item Env:DATABASE_URL
```

Сид створює 40 курсів, 80 потоків, 500 уроків, 200 студентів і 800 записів. Не запускайте його вдруге: він очищує
таблиці. Демо-акаунти описано в README.

## Оновлення

Кожне злиття в `main` запускає нове розгортання (`autoDeployTrigger: commit`). Міграції застосовуються автоматично під
час старту сервісу.

## Перевірка після розгортання

1. Відкрийте посилання (перший запит після простою може тривати близько хвилини): має завантажитися каталог курсів.
2. Увійдіть як `student001@example.com` / `Demo12345!`, відкрийте курс і запишіться на потік.
3. Перевірте HTTPS: у браузері замок, адреса починається з `https://`.
4. Оновіть сторінку на адресі `/courses/1`: вона має відкритися, а не показати помилку.

## Обмеження

- **Файли користувачів не зберігаються між перезапусками й розгортаннями.** Перед показом завантажте файл матеріалу чи
  домашньої роботи вже на розгорнутому сайті. Файли, завантажені раніше, можуть не відкритися.
- Сервіс засинає через 15 хвилин без запитів, перший запит після цього триває близько хвилини. Перед показом відкрийте
  сайт заздалегідь.
- Безкоштовна база видаляється через 30 днів після створення і не має резервних копій. Копію можна зробити локально:
  `BACKUP_MODE=local` і зовнішній URL у `DATABASE_URL` (потрібен клієнт PostgreSQL 16), див. [backup.md](backup.md).
