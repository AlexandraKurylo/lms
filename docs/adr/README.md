# Архітектурні рішення (ADR)

Кожне рішення, яке згодом буде дорого змінювати, фіксується окремим файлом (додаток Г методички).

Структура документа:

- **Статус** — прийнято / замінено / відхилено, дата.
- **Контекст** — конкретна ситуація, що змусила приймати рішення.
- **Розглянуті варіанти** — щонайменше два; відкинутий варіант описано чесно.
- **Рішення** — одне-два речення.
- **Наслідки** — і позитивні, і негативні.
- **Умова перегляду** — за яких обставин рішення перестане бути правильним.
